# France Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** All four maps for metropolitan France, with every country's data self-contained, and Spain unchanged.

**Architecture:** A `pipeline/countries/` package holds per-country configuration. `common.paths(cc)` gives each country's data, cache and output folders, and every pipeline takes `--country`. France gets its own base builder (`build_places_fr.py`) and its own hospital reader (FINESS + SAE). The web app reads `./data/<cc>/` and adds a country switch.

**Tech Stack:** Python 3.12 (stdlib, duckdb, openpyxl, py7zr for the SAE 7z), `npx mapshaper` (TopoJSON), TravelTime, TypeScript/MapLibre.

**Spec:** `docs/superpowers/specs/2026-11-22-france-design.md`

## Global Constraints

- Country codes are `es` and `fr`.
- **Paths:**
  - `data/<cc>/`;
  - `.cache/<cc>/{times,airports,internet,hospitals}/`;
  - `web/public/data/<cc>/{remoteness,airports,internet,hospitals}.{json,csv,csvt}` and `municipalities.topo.json`.
- **Spain stays identical:** after the move, its outputs regenerated from cache equal the committed ones byte for byte, ignoring `generated_at`.
- **France scope:** metropolitan only (departments 01–95, 2A, 2B). Corsica is `island:Corse`.
- **France categories:** exactly as the spec's table.
- **Hospital radius:** 150 km for tiers 2/3, 300 km for tier 1.
- **TravelTime quota errors** (HTTP 403/429 with a quota message): stop, keep the cache, report.
- **Merging:** finish by merging locally into `main`; never push.

## Review Focus

1. **Spain's outputs and the hash URLs** (`#airports`, `#internet`, `#hospitals`) keep working after the restructure. Tested in Task 1 (bytes) and Task 7 (browser).
2. **France loads only French files,** and Spain only Spanish ones. Checked through the browser network log in Task 7.
3. **Lambert-93 → WGS84** for FINESS: a wrong projection would put hospitals kilometres off. Tested against known points in Task 6.
4. **Corsica is its own zone:** a Corsican commune never reaches a mainland city or hospital. Tested in Tasks 2 and 6.
5. **Commune code formats:** INSEE codes are strings (`2A004`, `01001`). They must never be parsed as ints, and the `.csvt` must keep them as text. Tested in Task 2.

### Task 2: France base: communes, boundaries, places, city tiers
- **Create** `pipeline/countries/fr.py` with:
  - bbox `(-5.3, 41.3, 9.6, 51.15)`;
  - the metro department list;
  - the zone rule (2A/2B → `island:Corse`);
  - the curated `METROPOLES` (22 INSEE codes) and `PREFECTURES` (96);
  - map views (Métropole, Corse).
- **Create** `pipeline/build_places_fr.py`:
  - **Communes:** fetched per department from geo.api.gouv.fr (`fields=nom,code,codeDepartement,population,mairie,centre`).
  - **Tiers:** 1 for métropoles; 2 for préfectures or population > 100k; 3 for population > 50k.
  - **Output:** `data/fr/places.json` in the same shape as Spain's (`code, name, province, lat, lng, point, pop, tier, urban, island`).
  - **Boundaries:** download Etalab `2025/geojson/communes-100m.geojson.gz`, keep metro communes, and build `web/public/data/fr/municipalities.topo.json` (objects `municipalities` with `id` = INSEE code and `name`, plus `provinces` = departments dissolved) via `npx mapshaper -i … -filter … -o format=topojson quantization=1e5`.
- **Tests:**
  - tier rules on a fixture;
  - Corsica zone;
  - codes stay strings (`2A004`);
  - `places.json` has about 34,900 communes, and every commune in places is in the TopoJSON and vice versa (the real-data test is skipped if the files are missing).
- Commit with the data.

### Task 5: France airports
- **Curated list:** `data/fr/airports.py`-style list in `pipeline/countries/fr_airports.py` (same tuple shape and tests as Spain's), researched from current schedules.
  - It includes the foreign airports from the spec.
  - Zone: `island:Corse` for AJA, BIA, FSC, CLY.
- **Runs:** `compute_airports.py --country fr` with a cross-border pre-check (`--only GVA,LUX,CRL,FKB,SCN,GRO,EAS,BCN`), then the full run. The airport-point fixes (OSM stop / nudge) follow the same method as Spain if reach is 0.
- **Tests:** the invariants test is parametrised over both countries.
- Commit.

### Task 6: France hospitals
- **Create** `pipeline/hospitals_fr.py`:
  - **Inputs:**
    - FINESS géolocalisés CSV, cached in `.cache/fr/hospitals/`;
    - the latest SAE base administrative 7z, from which the URGENCES table gives FINESS géographique sites with general emergency activity.
  - **Hospitals:** `read_hospitals_fr() -> list[dict]` with the same keys as Spain (`codcnh` = FINESS géographique, `name`, `muni`, `lat`, `lng`, `tier`, `beds` None, `public`, `cath_lab` False).
  - **Coordinates:** converted from Lambert-93 with `lambert93_to_wgs84(x, y)`.
- **Placing:** `place_hospitals.py --country fr` skips OSM matching (FINESS has coordinates). It only snaps to the nearest stop within 400 m and applies `data/fr/hospital_overrides.json`.
- **Radius:** `compute_hospitals.py --country fr` with a per-destination `max_km` (`compute_times.origins_for` reads `d.get("max_km", MAX_KM)`).
- **Then:** `nudge_hospitals.py --country fr`, recompute.
- **Tests:**
  - Lambert-93: Notre-Dame de Paris x=652470,y=6862036 → 48.853,2.350 ±0.001; Ajaccio cathedral;
  - SAE filter fixture;
  - tier rules;
  - a per-destination radius test with `fake_post`.
- Commit.

### Task 7: Web: country switch and French copy
- `main.ts` gets a `country` state, a `#<cc>/<mode>` hash (old hashes map to es) and per-country `VIEWS` and title nouns ("rural Spain" / "rural France").
  - Data URLs are `./data/${country}/…`. Feature state is reset on a country switch: the TopoJSON is reloaded and merged data cleared.
- **Copy:** per-country "How this map is made" blocks (`data-for="<cc>-<mode>"`).
- **Category text:**
  - cities labels for France: "Métropoles | Hubs | All urban";
  - hospital help texts for France;
  - airports and internet reuse the shared labels.
- `npm run build`, then a browser check:
  - Spain unchanged in all 4 modes;
  - France in all 4 modes;
  - the country switch keeps the mode;
  - the network log shows only the selected country's files.
- Commit, run the final whole-branch review, apply the fix pass, then merge into `main` locally.
