# Airports Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** For every Spanish municipality, the public transport time to the nearest airport of each of 3 nested categories, year-round and with summer routes. It's written to JSON + CSV and shown on the existing map behind a Cities / Airports switch.

**Architecture:** A curated `pipeline/airports.py` list feeds a new `pipeline/compute_airports.py`. That script reuses `compute_times.Client` / `compute_all` with its own cache dir, aggregates 6 variants (3 tiers × year/summer), and writes `web/public/data/airports.{json,csv}`. `compute_times.py` gains a CSV export. The web page keeps one MapLibre choropleth. Airport values are merged into the same feature properties under different keys, and the fill expression switches key by mode.

**Tech Stack:** Python 3.12 stdlib + pytest; TypeScript, Vite, MapLibre GL 5.

**Spec:** `docs/superpowers/specs/2026-11-20-airports-design.md`

## Global Constraints

- No GitHub Actions changes. The pipeline runs locally; the user commits data.
- Same travel method as cities: arrivals 08:30 / 11:30 / 14:30 next Tuesday (Madrid time), best of three, cap 180 min, origins within 300 km in the same zone, origins = town centres from `data/places.json`.
- Airport location ids are `AIR:<IATA>`; they must never collide with 5-digit INE codes.
- Tiers: 1 Intercontinental (a route > 4,000 km great-circle), 2 Europe (≥ 1 route to another European country), 3 Any (any scheduled passenger flight). Nested. `tier_summer <= tier_year` whenever both are set; `None` = not a destination in that mode.
- City output (`remoteness.json`) must be byte-for-byte unchanged for the same cached inputs.
- CSV: UTF-8, header row, unreachable = empty cell, `code` zero-padded text, plus a QGIS `.csvt` sidecar typing `code` as String.
- Web copy is in English, matching the existing tone.
- Airports: Moroccan airports, Bragança and Vila Real are excluded, as are heliports and airports with no scheduled passenger flights. Excluded airports stay in `airports.py` with `None` tiers and a reason.

## Review Focus

1. **Island with no airport / Ceuta.** Formentera (`07024`) and Ceuta (`51001`) must get -1 in all 6 variants, never a mainland or Eivissa airport. Test in Task 3.
2. **Summer-only airport.** An airport with `tier_year=None, tier_summer=3` is never chosen in year mode and can be chosen in summer mode. Test in Task 3.
3. **QGIS reading `01001` as the integer 1001.** The join to boundaries breaks silently. The `.csvt` sidecar prevents it. Test in Tasks 1 and 3.
4. **Partial run overwriting real data.** `--limit` / `--only` must not write `airports.json` / `.csv`. Test in Task 3.
5. **Airports data missing or mode switched mid-hover.** The page shows a status message instead of a blank or broken map, and the tooltip closes on switch. Manual check in Task 5.

### Task 3: `compute_airports.py`

**Files:**
- Create: `pipeline/compute_airports.py`
- Test: `pipeline/tests/test_airports.py`

**Interfaces:**
- Consumes: `compute_times.Client`, `compute_all(..., cdir=)`, `cache_dir`, `ARRIVAL_TIMES`, `MAX_SECONDS`; `common.write_csv`, `AIRPORTS_OUTPUT_FILE`, `AIRPORTS_CSV`, `AIRPORT_CACHE_DIR`, `PLACES_FILE`; `airports.destinations()`.
- Produces:
  - `aggregate_airports(munis, airports: list[dict], results: dict[str, dict[str, int]]) -> tuple[list[dict], dict[str, list[int]]]`.
    - Airports are returned sorted by `(tier_summer, tier_year or 9, name)`.
    - Each row is `[y1, ya1, y2, ya2, y3, ya3, s1, sa1, s2, sa2, s3, sa3]`: minutes rounded, index into the returned list, -1/-1 when none. `y*` only considers airports with `tier_year` set and `<= tier`; `s*` uses `tier_summer`.
  - `build_output(places: dict, airports: list[dict], rows: dict) -> dict` returns the JSON shape from the spec:
    - `airports` entries are `[iata, name, country, lat, lng, tier_year, tier_summer, note]`;
    - `m` rows are the 12 values + `pop`;
    - `params` has `mode`, `arrival`, `arrival_times`, `max_minutes`, `population_year`, `notes`.
  - `airports_csv_rows(output: dict, munis: list[dict]) -> tuple[list[str], list[list]]`, with header `code,name,province,population,y1_min,y1_airport,y2_min,y2_airport,y3_min,y3_airport,s1_min,s1_airport,s2_min,s2_airport,s3_min,s3_airport` (airport = IATA).
  - CLI: `--limit N` (first N airports by tier), `--only MAD,OPO`, `--no-cache`.
    - Uses the cache dir `AIRPORT_CACHE_DIR / cache_dir(client).name`.
    - After computing, it prints `BORDER_CHECKS = [("36057","OPO"), ("06015","LIS"), ("20045","BIQ"), ("17066","PGF"), ("11022","GIB"), ("21010","FAO"), ("25243","TLS")]` as `Vigo → OPO: 74 min` or `unreachable`, skipping airports not computed.
    - With `--limit` or `--only` it **does not write** output files.

**Interfaces:**
- Consumes: `airports.json` shape from Task 3.
- Produces, in `airports.ts`:
  - `type Airport = [iata: string, name: string, country: string, lat: number, lng: number, tierYear: number | null, tierSummer: number | null, note: string]`
  - `interface AirportsData { generated_at: string; params: { arrival: string; max_minutes: number; population_year: number | null; notes: string[] }; airports: Airport[]; m: Record<string, number[]> }`
  - `loadAirports(): Promise<AirportsData | null>` returns `null` on 404 or a network error.
  - `airportProps(row: number[]): Record<string, number>` gives keys `y1, ya1, … y3, ya3, s1, sa1, … s3, sa3`.
  - `airportMarkers(d, tier: Tier, summer: boolean): FeatureCollection` uses properties `{ name, iata, tier }`, where tier is the effective tier in that mode, and only includes airports eligible at `<= tier`.
  - `airportTooltip(d, p: Record<string, unknown>, tier, summer): string` produces the time plus `to Málaga (AGP)`; foreign airports read `to Porto (OPO, Portugal)`; when none, `no <noun> within 3 h`.
  - `airportHeadline(d, tier, summer): string | null` is population-weighted over **all** municipalities: `<b>X%</b> of people are more than <b>1 hour</b> by public transport from <noun with article>.`
  - `airportCounts(d, summer): [number, number, number]`
  - `AIRPORT_TEXT: Record<Tier, { label: string; noun: string; help: string }>` holds:
    - 1: `Intercontinental` / `an intercontinental airport` / `Airports with flights longer than 4,000 km: the Americas, the Gulf, Asia.`
    - 2: `Europe` / `an airport with European flights` / `Airports with at least one flight to another European country.`
    - 3: `Any airport` / `an airport` / `Any airport with scheduled passenger flights.`
